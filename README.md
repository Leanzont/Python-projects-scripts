# Python Projects & Scripts

Python scripts and CLI tools for AWS automation — boto3, requests, argparse, socket, json, OOP.

Built as part of a self-directed learning path toward a Cloud/DevOps Engineering career.
Each project focuses on a specific concept and is documented with a dedicated README.

## Projects

| Project | Description | Libraries |
|---------|-------------|-----------|
| [student_management](./student_management/) | CLI app to manage students, add grades, and calculate averages | OOP |

## Tech stack

- Python 3
- boto3 — AWS SDK for Python
- requests — HTTP requests to external APIs
- argparse — CLI argument parsing
- socket — low-level networking
- json — data serialization
- OOP — Object-Oriented Programming

## Setup

```bash
git clone https://github.com/Leanzont/Python-projects-scripts
cd python-projects-scripts
pip install boto3 requests
```

Each project has its own README with specific instructions on how to run it.
